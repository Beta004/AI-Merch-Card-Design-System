01

Overview · 概览

Tokens 是设计系统的基础层：颜色、字号、圆角、阴影、间距等都以 CSS 变量的形式落在 tokens.css。 原子组件和商卡都只消费 tokens，不再定义原始色值。点击任意色块可以复制变量名到剪贴板。

02

Color · 颜色

网站外壳默认使用白色与浅灰构成亮色基调，黑色承担主按钮、高层级文字与关键结构；同时保留可切换的曜石黑暗色模式。 --accent 柔紫只用于关键交互，冷蓝只用于低透明环境光；Joybuy 红 #E1251B 保留给 logo、品牌锚点与真实商卡业务内容。 以下色值以默认亮色模式为准；网站 chrome 与商卡设计系统彼此隔离，任何网站配色调整都不会改变商卡预览。

04

Radius · 圆角

5 档圆角覆盖 90% 场景。原子标签用 xs、卡片图片用 sm、大卡片和列表容器用 md、面板/模态用 lg、胶囊按钮用 pill。

--r-xs
4px · 标签、内框
--r-sm
6px · 卡片图片、按钮
--r-md
10px · 卡片、表格、列表
--r-lg
14px · 面板、模态
--r-pill
999px · 胶囊 chip / toggle
05

Shadow · 阴影

3 层阴影：shadow-1 hover 抬起、shadow-2 弹层浮起、shadow-focus 键盘焦点环。 阴影颜色使用低透明度黑而非深灰，与 TDesign React 保持一致。

--shadow-1
卡片 hover · 双列表格 hover
--shadow-2
下拉菜单 · 弹层 · 模态
--shadow-focus
键盘 focus ring · 红色 15% 光晕
