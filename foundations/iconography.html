01

Overview · 概览

全部图标由 Figma REST API 从 Joybuy 商卡组件库导出为 SVG，落在 site/assets/figma-atoms/<category>/<name>.svg。 点任意图标即可复制 var()-可用的相对路径。禁止手绘 icon 二次修改，改动请在 Figma 源文件里更新后重新导出。

Rule
视觉一致是"视觉一模一样"的底线—— 商卡里的每一个图标都必须来自这份目录， 不允许用 Unicode 字符（如 ★）或 CSS 手绘（如 border 拼三角）作为图标使用。
02

Highlights · 亮点标签

用户扫视商卡时最先捕获的视觉锚点。Product Highlights 走枚举驱动（7 枚 SVG 对应 7 个 Figma 变体）， AI Recommendation 与 Dietary Badges 是补充分组。

03

Interaction · 交互

直接与用户手指发生交互的按钮 · 加购按钮全 11 状态、收藏/点赞按钮的 3 状态。

04

Fulfillment · 履约库存

物流承诺、卖家类型、库存状态相关的图形。灰阶为主，用来在信息层次上把"次级信息"和主内容拉开距离。

05

Price · 价格营销

价格主行、促销副行、大促标签等富含数字的组合。这些 SVG 内含 tabular-nums 版式，直接嵌入卡片无需二次排版。

06

Attribute · 属性辅助

颜色/能效/等级等属性型图形，用于辅助信息展示。使用频率较低但每张商卡都可能出现一到两个。
