01

Overview · 概览

小图商卡是固定四列的轻量商品入口，只包含商品图片与价格两个槽位。Figma 组件仅区分“有参考价”和“仅价格”两种排版， 不在组件层提供列数、角标或品牌入口变体。

变体 · Variant
分类 · Category
变体只改变价格第二行是否出现；商品图片、卡片数量与间距保持不变。

03

Types · 类型

Figma 母组件只有两种价格排版，卡片数量与容器布局由使用页面决定，不作为组件变体。

With reference price · 有参考价
主价格下方显示 RRP / WAS，适合需要表达价格优惠的入口。
Price only · 仅价格
只显示主价格，第二行完全收起，不保留空白占位。

06

When to Use · 何时使用

Small Dynamic 与 Mini / Horizontal 的分界是"是否承担决策"—— Small Dynamic 只承担"点击入口"， 用户点了之后跳去详情页做决策；Mini / Horizontal 是承载决策本身的卡。

选 Small Dynamic 当
  • 一屏想曝光 6+ 商品或品牌入口
  • 每张 tile 只引导点击，不需用户决策
  • 空间极受限（顶部条 < 100 px、侧边栏 < 260 px）
  • 商品之间关联度弱（不同品牌 / 类目）
  • 视觉侧重"密度 · 一览" > 单卡信息量
选 Mini 或 Vertical 当
  • 用户要在卡内做决策（比较价格、评价、履约）
  • 加购 / 收藏 / 改数量等操作在卡内完成
  • 一屏 < 6 个商品，每张卡都是主内容
  • 需要展示标题 / 评价 / 履约 / 卖家等辅助字段
  • 视觉侧重"决策 · 信息量" > 曝光密度
DO
  • Small Dynamic 只用在"入口位"—— 品牌馆、快捷入口、直播清单
  • 控制字段数量 · label + price 择一，或都要但 badge/ribbon 至多一个
  • 直播 tile 用 ribbon--live 脉冲动画拉住注意力，售罄立即切 --sold-out
  • 品牌入口场景直接省 price 字段，图像 padding 加大更透气
DON'T
  • 别在购物车 / 订单主列表用 Small Dynamic · 信息不够用户改数量
  • 别同时塞 badge + ribbon · tile 只有一个视觉焦点
  • 别把 tile 尺寸做到 100+ px · 那就该升 Mini 或 Vertical 了
  • 别用 title 完整名称塞进 label · 只放品牌名或活动名，一行必截
